# Sarvesh Solanke — Portfolio

Live site: [sarvesh.dev]( https://sarveshsolanke.github.io/portfolio/)

Personal portfolio built to showcase my software engineering and AI projects, professional experience, and technical background. Single-page site built with vanilla HTML, CSS, and JavaScript, hosted on GitHub Pages.

## About me

Master of Applied Computing student at the University of Windsor (graduating December 2026), with 2.5 years of software engineering experience at Capgemini building Python and Java applications on Azure cloud infrastructure for financial services clients. Background also includes embedded systems and autonomous navigation, including a patent-pending GPS-independent positioning algorithm and an autonomous drone surveillance system.

## What's in this repo

```
portfolio/
├── index.html      single-page site: about, experience, projects
└── assets/         project screenshots and images used on the site
```

This repo contains only the portfolio site itself. Individual projects referenced on the site (DRONOMINES, AI Code Review Assistant, IN-MAPS, etc.) are linked to their own separate repositories where the actual project code lives.

## Tech stack

Vanilla HTML, CSS, and JavaScript, no frameworks or build step. Chosen deliberately to keep the site fast, dependency-free, and easy to host on GitHub Pages.
